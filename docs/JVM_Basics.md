#What is JDK, JRE, JVM
JDK - Complete Java development toolkit to  build java application contains both JRE and JVM
JRE - Contains core library to run Java application contains JVM
JVM - It executes the compiled java byte code. JVM is different for every machine type.

#What is bytecode
Bytecode is readable and executable by JVM, bytecode comes between java code and machine readable language. 
Bytecode makes Java platform independent.

#What does “write once, run anywhere” mean (1–2 short paragraphs)
We write pure java code, once we compile it converted to bytecode. Now this bytecode can be understandable by any JVM.
