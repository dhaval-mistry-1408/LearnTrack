#Brief explanation of Hello World program.

public - is an access access modifier means this class is visible to other classes.

class - is a keyword to create classes in java, Class is blue print or template used to create objects. 

main method - main method is special method in java as it is entry point of any java program. 

public means accessible from anywhere, static used as JVM can call without object, void means return nothing, string args accept data from command line.
